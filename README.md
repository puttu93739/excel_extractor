# Excel_extractor
Excel Extractor is a scalable, enterprise-grade Python tool designed to automatically extract, clean, and count group names embedded within structured comment fields inside Excel spreadsheets.

Key Features

Robust Pattern Extraction
Detects values inside [code]<I>...</I> format with precision.

Dynamic and Configurable
Users can specify the input file, target column, and tag name at runtime.

Object-Oriented Design
Clean and modular class-based implementation perfect for enterprise use.

Accurate Group Counting
Returns a dictionary-style frequency map for all extracted groups.
 
PyTest Coverage
Includes comprehensive unit tests for text parsing, Excel reading, and error handling.

Excel Support via Pandas
Seamlessly reads .xlsx files using robust, tested library support.

Production Ready
Simple to integrate into pipelines, frameworks, automation scripts, or API backends.
